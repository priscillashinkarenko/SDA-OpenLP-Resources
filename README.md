# SDA-OpenLP-Resources
Free OpenLP resources for Seventh-day Adventist churches

This project provides SDA hymns, OpenLP themes, and additional resources
to help churches create beautiful, consistent worship presentations with OpenLP.

---

## Download the Resources

### Complete Pack

Want everything in one download?

**[Download the Complete Pack](../../releases)**

download.

### Individual Resources

Prefer to download only what you need?

- SDA Hymns
- OpenLP Themes
- Additional resources and add-ons

## New to GitHub?

No problem!

You **do not need a GitHub account** to download these resources.

### To download a resource:

1. Click **[Releases](../../releases)** above.
2. Find the resource or pack you want.
3. Scroll down to **Assets**.
4. Click the file you want to download.
5. Your download will begin automatically.

### Want everything?

Choose the **Complete Pack** release and download the `.zip` file listed
under **Assets**.

You do not need to download the individual files if you want the complete
collection.

## Using the Resources in OpenLP

After downloading the resources, you'll need to import them into OpenLP.

For step-by-step instructions for importing:

- Songs
- Themes
- Add-ons
- Additional OpenLP resources

visit the SDA OpenLP Resources website:

**[sda-openlp-resources](https://sites.google.com/view/sda-openlp-resources)**

The website also contains additional download instructions and installation
help.

---

## About

SDA OpenLP Resources was created to make it easier for Seventh-day Adventist
churches to use OpenLP for worship services.

The goal is to provide useful, ready-to-use resources while keeping them easy
to find, download, and install.

---

## OpenLP

These resources are designed for use with **OpenLP**, a free and open-source
church presentation platform.

Learn more about OpenLP:

**[openlp.org](https://openlp.org/)**
